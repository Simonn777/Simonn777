# Profile technology icons

Unmodified SVG icons from [Devicon](https://github.com/devicons/devicon),
pinned at commit `6a37858047b0e8d9c9c0e68f4a071fc410652e89`. Each file was retrieved from
`icons/<name>/<name>-original.svg` on October 16, 2026.

The upstream license is preserved in `DEVICON-LICENSE.txt`. Product names and
logos identify tools used in the projects; they do not imply endorsement.
The profile also lists the names as text for accessibility.

These files are stored locally in the repository; no remote stats service,
profile counter, or badge generator is required.
