# Applications and team contributions

These summaries describe existing work separately from the new public
VectorTile systems lab. Repository privacy and team ownership are stated
explicitly. Live sites show current presentation, not independent proof of
historical adoption or revenue.

## Tufts Review

[Tufts Review](https://tuftsreview.org) is an independent student campus guide.
As a co-founder, I co-built the React/Next.js application, including department
filters and pagination, and verified listings against official university
sources. The application uses Supabase for its database and authentication.

The product helps students find resources and share reviews. It is not an
official Tufts University publication. The live guide is the public entry
point; its source is not published in this profile.

## Blue Orchard

[Blue Orchard](https://blue-orchard.net) is a storefront for Yunnan handmade
textiles. I built its React/Next.js and TypeScript application with a Supabase
catalog, persistent browser cart, and Stripe Checkout.

The codebase includes server-side Checkout handling, signature-verified
payment webhooks, order persistence, inventory/fulfillment paths and
transactional-email handling. Payment confirmation is handled on the server;
the client success page alone is not treated as proof of payment.

The source remains private. The public storefront's present launch state is
separate from the implementation described here. This summary does not claim
newly measured traffic, revenue, or conversion results.

## JumboCode / LexShareWare

As a JumboCode software developer, I worked on inventory management,
authentication and database functionality for LexShareWare, a dishware-lending
application for Lexington Zero Waste. The team stack included React, Next.js,
PostgreSQL and Prisma.

This is team contribution, not sole ownership. Team code is not redistributed
here, and private access is not implied by this summary.
