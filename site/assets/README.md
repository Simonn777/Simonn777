# Asset provenance

- `vectortile-demo.jpg` is an actual screenshot of the public VectorTile demo,
  captured on October 12, 2026. Its browser visualization is distinct from the
  recorded C++/Python benchmark results.
- Instrument Serif (regular and italic), by Rodrigo Fuenzalida, and Manrope
  (regular and semibold), by the Manrope Project Authors, are self-hosted
  unmodified font files retrieved through Google Fonts. The corresponding
  SIL Open Font License files are included here.
  - https://github.com/google/fonts/tree/main/ofl/instrumentserif
  - https://github.com/google/fonts/tree/main/ofl/manrope
- `mark.svg` is the site's typographic monogram.

No font CDN, analytics script or third-party JavaScript is required at runtime.
